# Sales Data Analysis & Interactive Dashboard

## Project Overview

This project analyzes sales data to understand sales performance, profitability, regional trends, category performance and product performance.

## Tools Used

- Microsoft Excel
- Power BI
- DAX

## Key Analysis

- Total sales and profit analysis
- Monthly sales trends
- Regional sales performance
- Category-wise sales analysis
- Product performance
- Interactive filtering using Power BI slicers

## Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Profit Margin KPI
- Monthly Sales Trend
- Sales by Region
- Sales by Category
- Sales by Product
- Interactive Region and Category filters

## Files

- Sales_Data.xlsx - Source dataset
- Sales_Dashboard.pbix - Power BI dashboard
- dashboard.png - Dashboard preview

## Learning Outcomes

Through this project, I practiced data cleaning, Excel analysis, Power BI visualization, KPI creation and basic DAX measures.
